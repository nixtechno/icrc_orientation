# Badges and printing

Administrators open **Badges & printing** in the portal sidebar, or the badge action on an existing profile. The module uses the application's Admin, Facilitator and Staff profile types; it does not create accounts or alter access permissions.

## Create and edit

1. Search for an enrolled profile or filter by type.
2. Choose **Create badge**, or **Edit / print badge** for an existing badge.
3. Review the first name, surname, title and organization. **Save profile & badge** updates the underlying profile and its badge snapshot. Account role, permissions and invited email stay unchanged.
4. Adjust name/title/organization sizes if needed. Text is fitted automatically. These appearance adjustments apply only to the print view and its PDF link.

Standalone facilitator directory profiles are also supported. Linked facilitator directory entries use the account profile in the profile picker. Previously issued standalone badges remain accessible.

## Print

The default face is **97 × 138 mm**. Folded output places two faces on a **97 × 276 mm** sheet, with the lower face rotated 180 degrees. Single-face output is also available. Existing customized dimensions are retained; edit **Badge design & dimensions** to change them.

The browser workbench and PDF use the same artwork and bundled DejaVu font. The badge uses ICRC SCODEX branding, the configured programme dates/venue, role colour, a verification QR code and a stable collection code. Typography follows the supplied reference; unrelated event names, dates, organizations and profile categories were not imported.

Use **Print badge** for the browser dialog or **Open PDF** for the print-ready PDF. Use actual size/100% scale and disable browser headers/footers. Physical printer calibration and QR scanning on printed stock still need a venue test. Profiles edited in the browser must be saved before printing.

Select profiles to generate/regenerate a batch, or select issued badges to open a batch PDF. Opening a preview, printing dialog or PDF does not confirm a successful physical print.

## Verify and collect

The QR opens an administrator-protected verification page. Check the holder against the displayed profile before confirming collection. The collection code is searchable in **Badges & printing**.

The module tracks **Badge printed**, **Badge collected**, and **Training materials collected** separately. Collection requires printing confirmation. Repeating a confirmation preserves the original timestamps. Administrator corrections and profile/generation/printing/collection changes are audited.

Regenerating or changing badge profile details increments its version and resets badge printing/collection status. Material collection and the collection code are retained. A badge is an identification/collection aid; it does not sign staff into attendance or grant application permissions.

## Validation

Coverage includes all three categories, linked and standalone profiles, profile synchronization, role immutability, protected QR verification, collection timestamps, batch PDF page count, layout/size validation and programme isolation. The browser preview and actual generated PDF were visually reviewed in Chrome.
